# Inventaire des Tests de l'Application Ariane

Ce fichier recense l'ensemble des tests automatisés pour l'application Ariane. Chaque test garantit le bon fonctionnement d'une partie spécifique du code.

| Fichier de Test (`ariane_app/test/...`) | Description de la Recette (Objectif du Test) |
| :--- | :--- |
| `ariane_all_results_screen_test.dart` | Vérifie l'affichage correct de l'écran qui liste tous les résultats des jeux. |
| `ariane_menu_screen_test.dart` | Vérifie l'affichage du menu principal et la navigation vers chaque jeu. |
| `ariane_result_screen_test.dart` | Vérifie l'affichage de l'écran de résultat après avoir terminé un jeu. |
| `ariane_screen_test.dart` | Vérifie l'écran d'accueil principal de l'application. |
| `calcul_game_page_test.dart` | Vérifie l'interface et les interactions de base du jeu de calcul. |
| `labyrinth_game_page_test.dart` | Vérifie l'interface et les interactions de base du jeu de labyrinthe. |
| `parameter_page_test.dart` | Vérifie l'écran des paramètres (probablement le changement de langue). |
| `score_manager_test.dart` | **(Test Unitaire)** Vérifie la logique de sauvegarde et de récupération des scores. |
| `scratch_game_page_test.dart` | Vérifie l'interface et les interactions de base du jeu de grattage. |
